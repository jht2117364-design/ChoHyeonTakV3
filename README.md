# IO Insight 2023 · 산업연관분석 웹앱 V3

## 2. 분석 화면 사용법

1. 왼쪽(모바일은 화면 상단)에서 산업분류(33/83/165/380개) 선택 → **Excel 데이터 불러오기**.
2. 기존 기능: 데이터 탐색, 유발효과 분석, 산업 간 비교.
3. **파급효과 순위:** 지표 선택 → 상위 12개 그래프 또는 전체 표 확인 → CSV.
4. **산업연관 히트맵:** 계수 종류와 대상 산업 선택 → **히트맵 생성** → 셀 클릭/키보드 선택으로 공급·사용 산업 계수 확인.
5. **직접·간접효과 분해:** 산업과 증가액 선택 → **효과 분해하기** → 생산유발액 단계별 해석과 CSV.
6. **정책 시나리오:** 서로 다른 산업 A·B, 동일 총수요, 사용자 맞춤 배분 비율 선택 → **4가지 시나리오 비교하기** → CSV.
7. **산업 보고서:** 산업 선택 → 보고서 생성 → **인쇄/PDF 저장** 클릭 → 브라우저에서 인쇄하거나 `PDF로 저장` 선택.

> 산업분류를 바꾸면 새 분류의 Excel을 다시 불러와야 합니다. 기존 시나리오는 초기화됩니다. 처음 실행 시 CDN에서 Python 런타임과 패키지를 설치하므로 인터넷 연결이 필요합니다.

### 산업연관 히트맵 범위

- 통합대분류(33개): **33×33 전체 행렬**을 시각화합니다.
- 통합중분류·소분류·기본부문(83·165·380개): 한 화면의 가독성과 성능을 위해 **대상 산업과 대상 열의 상위 24개 공급 산업, 총 25개 산업의 부분행렬**을 보여줍니다. 전체 산업의 관계를 전부 보여주는 화면이 아닙니다.
- 히트맵의 색상은 현재 선택한 부분행렬 내 최대 절댓값이 아닌 **최댓값에 상대화**한 값입니다. 서로 다른 분류/계수 유형에서 색의 진하기를 직접 비교하면 안 됩니다. 정확한 계수는 각 셀의 설명에 표시됩니다.

## 3. 계산 원리 및 단위

각 수요 충격은 **국산품 최종수요 증가**로 가정합니다. 산업별 **총산출**과 **부가가치**는 다른 경제지표입니다.

- 생산유발액: `Δx = L Δf`, `L = (I − Aᵈ)⁻¹`
- 부가가치유발액: `Δv = V Δf`, `V = diag(v)L`
- 수입유발액: `Δm = M Δf`, `M = AᵐL`
- 산업별 배율: 해당 계수행렬의 **열 합계**
- 단계별 분해: `Δx = Δf + AᵈΔf + (L−I−Aᵈ)Δf`

`Aᵈ`: 국산투입계수, `Aᵐ`: 수입투입계수, `L`: 생산유발계수, `V`: 부가가치유발계수, `M`: 수입유발계수.

- **Excel 거래표 / 내부 Python 금액:** 백만원
- **웹앱 입력·표시 금액:** 억원 (`1억원 = 100백만원`)
- **계수:** 무차원

생산유발액에는 중간재 거래가 포함되므로 **GDP 증가액과 같지 않습니다.** 정책 시나리오는 투자비용이나 재정 지출의 효과를 추정하는 인과분석이 아니라 같은 규모의 국산품 최종수요 증가분을 가정해 비교하는 정태적 모형 실험입니다.

## 4. 재현 가능한 검증 사례

통합대분류 33개에서 건설(F), 교육서비스(P)에 각각 국산품 최종수요 100억원 증가를 가정합니다.

| 지표 | 건설 F | 교육서비스 P | F·P 각 100억원 동시 증가 |
| --- | ---: | ---: | ---: |
| 수요 증가액 | 100억원 | 100억원 | 200억원 |
| 총생산유발액 | 205.84억원 | 156.90억원 | 362.74억원 |
| 총부가가치유발액 | 79.61억원 | 90.66억원 | 170.27억원 |
| 총수입유발액 | 20.39억원 | 9.34억원 | 29.73억원 |
| 생산유발배율 | 2.0584 | 1.5690 | 1.8137 |

**V3 분해 검증:** 건설업 100억원 충격의 총생산유발액은 **직접 100.00억원 + 1차 중간재 약 54.68억원 + 2차 이상 약 51.16억원 = 약 205.84억원**으로 구성됩니다. 원본 계수행렬의 고정계수 정태적 효과이며 향후 건설업의 실제 생산 성장률이 아닙니다.

## 6. GitHub Pages 배포

**기존 V2 `HyeonTak` 저장소를 보존하려면** 새 공개 저장소 `io-insight-2023-v3`를 생성하는 것을 권장합니다.

1. [GitHub 새 저장소](https://github.com/new)에서 **Public** `io-insight-2023-v3` 생성.
2. 프로젝트 ZIP을 내려받아 압축을 해제합니다.
3. 내부 파일 `index.html`, `style.css`, `app.js`, `worker.js`, `model.py`, `README.md`, `VALIDATION.md`, `.nojekyll`, `data/`를 저장소 루트에 업로드하고 **Commit changes**.
4. **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
5. `https://<사용자명>.github.io/io-insight-2023-v3/`를 열고 실제 웹앱에서 Excel 불러오기와 각 기능을 점검하세요.

이미 가지고 있는 V2 저장소를 덮어쓸 수도 있지만, 이 경우 V2가 변경되므로 기존 상태를 별도로 보존해야 합니다.

### 로컬 테스트

```bash
python -m http.server 8000
```

프로젝트 루트에서 명령 실행 후 `http://localhost:8000/` 접속. `index.html`을 더블클릭하는 `file://` 방식은 Excel 다운로드 및 Worker 실행에서 보안 오류가 발생할 수 있습니다.

## 7. 한계·자료 사용 유의

- 2023년 한 해의 산업구조·고정 투입계수에 기반한 **정태적 시뮬레이션**입니다.
- 가격 변화, 기술 변화, 생산능력·공급제약, 예산의 조달 비용, 실제 고용효과 및 인과효과를 반영하지 않습니다.

- 수입유발계수 정의는 한국은행 원본 계수 범위에 따릅니다.
- 공개 GitHub 저장소에 원본 Excel 파일을 재배포하는 방식이 허용되는지는 **별도로 확인해야 합니다**. [한국은행 저작권보호방침](https://www.bok.or.kr/portal/main/contents.do?menuNo=200228)과 자료 상세 페이지의 이용조건을 확인해야 합니다.
